# FineReport 11 · CPT 模板包说明

本目录为「帆软 FineReport 11 · CPT 报表生成技能包」配套的 8 个可导入模板。
全部以官方 demo 真实 `.cpt` 为底稿改造而成，严格保持 FineReport 约定：根节点 `<WorkBook>`、UTF-8 无 BOM、LF 换行、零缩进、无 DOCTYPE、中文/SQL 一律 CDATA 包裹、`class` 为 Java 全限定名。

- 生成日期：2026-10-01
- 适用版本：FineReport 11（设计器可直接导入/打开）
- 数据连接名：统一使用 demo 内置连接 **FRDemo**（导入前请确保设计器已配置同名数据连接，内含 `销量 / 订单 / S订单 / 客户 / up` 等表）

## 二、各模板详解

### 01_基础查询报表.cpt
- **功能描述**：最基础的分组汇总报表示例。SQL 数据集直连 FRDemo `销量` 表，按「地区→销售员」纵向分组，销量列做 Sum 汇总，另加一列 CountFunction 记录数；含一个报表参数（地区）与两套基础命名样式。
- **导入方法**：设计器 → 文件 → 打开 → 选择本文件；或直接拖入设计器工作区。
- **修改要点**：
  - 改 SQL：定位 `<TableData name="ds1" ...><Query><![CDATA[...]]>`，把 `select * from 销量` 换成自己的查询。
  - 改表头：`<CellElementList>` 下 `<C c="0" r="0">` 等三个 `<O><![CDATA[...]]></O>` 文本。
  - 改汇总列：销量列 `<RG ... SummaryGrouper><FN><![CDATA[com.fr.data.util.function.SumFunction]]></FN>`，记录数列同为 SummaryGrouper + `CountFunction`。
  - 报表参数：`</ReportParameterAttr>` 前的 `<Parameter><Attributes name="地区"/><O><![CDATA[华东]]></O></Parameter>`。
- **预期效果**：分页预览按地区/销售员分组列出销量合计与记录条数，表头带样式底色与边框。

### 02_参数联动报表.cpt
- **功能描述**：多参数 + 参数面板控件齐全。主控件为多级下拉树（地区→省份→城市三级级联：ds2 取地区、ds3 按 layer1 取省份、ds4 按 layer2 取城市），另加一个独立 ComboBox「运输方式」；ds1 主数据按所选城市 + 运输方式动态过滤。
- **导入方法**：同 01。
- **修改要点**：
  - 参数面板控件：`<ReportParameterAttr>` 内 `<ParameterUI>...<Layout>...<Widget class="...WAbsoluteLayout$BoundsWidget">` 段，每个控件一个 BoundsWidget（InnerWidget 类型 + BoundsAttr x/y/width/height）。
  - 级联数据集：ds3 的 SQL `where 货主地区='${layer1}'`、ds4 `where 货主省份='${layer2}'`——layer1/layer2 即上一级控件值，改级联关系改这里。
  - 新增独立下拉：复制一段 ComboBox BoundsWidget，并在 ds1 的 `${if(...)}` 片段里加对应过滤。
- **预期效果**：顶部参数面板选地区后省份/城市树自动刷新，选运输方式后表格数据联动过滤；点「查询」按钮提交。

### 03_填报入库报表.cpt
- **功能描述**：填报模式 + 智能提交入库。沿用 demo `产品月销量情况录入表` 的 `ReportWriteAttr > BuiltInSQLSubmiter > IntelliDMLConfig` 结构（目标表 `up`，FRDemo 连接），并补上报填工具栏（提交入库/数据校验/添加行/删除行）。业务内容已泛化，不含任何私有表名/连接名。
- **导入方法**：用「填报预览」打开（`PreviewType=1`）。
- **修改要点**：
  - 改目标表：`<ReportWriteAttr><SubmitVisitor ...><DMLConfig ...><Table schema="" name="up"/>`，把 `up` 换成自己的物理表。
  - 字段映射：每个 `<ColumnConfig name="列名" isKey="true/false">` 用 `<ColumnRow column row/>`（0 基坐标）指向单元格；isKey=true 为主键。
  - 改工具栏：`<ReportWebAttr><WebWriteContent><ToolBars>` 下各 `Widget class="com.fr.report.web.button.write.*"`（Submit/Verify/AppendRowButton/DeleteRowButton）。
  - 填报条件：`<DMLConfig>` 末 `<Condition class="com.fr.data.condition.FormulaCondition"><Formula><![CDATA[len(D6)!=0]]></Formula>`。
- **预期效果**：填报预览下可新增行、编辑销量单元格、点「提交入库」按主键 upsert 到目标表。
- **注意**：实际入库需 FRDemo 库中存在 `up` 表及对应字段；仅导入/预览结构不入库。

### 04_图表报表.cpt
- **功能描述**：同一张表内两个 VanChart 图表单元格——上方饼图（PiePlot4VanChart）展示各地区应付金额占比，下方柱形图（VanChartColumnPlot）展示各地区应付金额；均绑 ds1（FRDemo 订单表，货主国家='中国'）。
- **导入方法**：同 01，普通预览。
- **修改要点**：
  - 饼图数据：饼图 `<ChartDefinition><OneValueCDDefinition seriesName="货主地区" valueName="应付金额" function="...SumFunction">`。
  - 柱图数据：柱图 `<ChartDefinition><MoreNameCDDefinition><CategoryName value="货主地区"/><ChartSummaryColumn name="应付金额" function="...SumFunction"/>`。
  - 两个图表分别是两个 `<C ...><O t="CC">...</C>` 单元格（饼图在 r=0，柱图在 r=9），改位置调 `c/r/cs/rs`。
  - 标题：各 `<Title4VanChart><Title><O><![CDATA[...]]></O>`。
- **预期效果**：一页上下两个图表，饼图看占比、柱图看对比。

### 05_按钮JS事件报表.cpt
- **功能描述**：自定义按钮 + JS 事件 + 超链接。单元格 FreeButton（afterinit 初始化、click 取值回填并关窗）、复选框 CheckBox（statechange 带参 JS）；另加报表加载结束 afterload 弹窗，表头单元格挂 Web 超链接。
- **导入方法**：同 01。
- **修改要点**：
  - 按钮 JS：`<C><Widget class="com.fr.form.ui.FreeButton"><Listener event="click"><JavaScript ...><Content><![CDATA[...]]></Content>`。
  - 控件带参事件：`<Listener event="statechange">` 内 `<Parameters>` 用 `<O t="XMLable" class="com.fr.base.Formula">` 传单元格值。
  - 报表级 afterload：`<ReportWebAttr><Listeners><Listener event="afterload">`。
  - 超链接：单元格内 `<NameJavaScriptGroup><NameJavaScript><JavaScript class="com.fr.js.WebHyperlink">`。
- **预期效果**：勾选记录后点按钮处理，加载完弹出 toast，点表头打开帮助网页。

### 06_样式定制报表.cpt
- **功能描述**：命名样式 + 条件属性高亮。`<StyleList>` 定义表头底色/数据白底/日期格式 `yyyy-MM-dd`/数字格式 `#0.00` 等命名样式；数据区带两条条件属性——偶数行紫色背景（BackgroundHighlightAction）、运货费>100 字体变红（ForegroundHighlightAction）；主题标记为「自定义样式主题」。
- **导入方法**：同 01。
- **修改要点**：
  - 命名样式：`<StyleList>` 下每个 `<Style horizontal_alignment=...><FRFont .../><Background .../><Border>...`，单元格用 `s="索引"` 引用。
  - 条件高亮：单元格内 `<HighlightList><Highlight><Condition class="com.fr.data.condition.FormulaCondition"><Formula><![CDATA[ROW()%2==0]]></Formula>`，动作换 `BackgroundHighlightAction` / `ForegroundHighlightAction` / `FRFontHighlightAction` 等。
  - 颜色为 int 反色编码（白 -1、黑 -16777216）。
- **预期效果**：订单列表斑马纹隔行变色，运货费超 100 的数字自动标红。

### 07_脚本报表.cpt
- **功能描述**：脚本/公式变量/单元格事件综合示例。报表级 afterload 脚本（打印加载时间）、报表参数 `p` 公式默认值 `=NOW()`（公式变量）、复选框 statechange 单元格 JS。
- **导入方法**：同 01。
- **修改要点**：
  - 报表脚本：`<ReportWebAttr><Listeners><Listener event="afterload"><Content><![CDATA[...]]></Content>`。
  - 公式变量：`</ReportParameterAttr>` 前 `<Parameter><Attributes name="p"/><O t="XMLable" class="com.fr.base.Formula"><Attributes><![CDATA[=NOW()]]></Attributes></O></Parameter>`，单元格里用 `$p` 引用。
  - 单元格 JS：数据区 CheckBox 的 `<Listener event="statechange">`。
- **预期效果**：加载后控制台打印脚本日志，公式变量在参数面板可见，勾选触发单元格事件 JS。
- **说明**：demo 240 个 cpt 中未提供「脚本型数据集」类节点，本模板以报表级 afterload JS + 单元格事件 JS 作为「脚本」载体。

### 08_Java自定义函数报表.cpt
- **功能描述**：单元格公式引用 Java 自定义函数。在分组销量表下方加一行，用 `=MySum(C2)` 对销量列求和——`MySum` 即自定义函数占位名。
- **导入方法**：文件可正常导入设计器；**预览需先安装提供 MySum 函数的自定义函数插件**，否则该单元格公式会报「函数不存在」。
- **修改要点**：
  - 自定义函数公式：`<C c="2" r="2"><O t="XMLable" class="com.fr.base.Formula"><Attributes><![CDATA[=MySum(C2)]]></Attributes></O>`。
  - 把 `MySum` 改成你插件实际注册的函数名；括号内 `C2` 为目标单元格/列。
- **预期效果**：导入后结构正常；装好对应函数插件后，合计行显示自定义函数计算结果。配合 `references/features.md` 的 Java 专题说明使用。

## 三、导入与自检约定

- 导入：设计器「文件 → 打开」选择 `.cpt`；或把文件放入 `%FineReport%\webroot\WEB-INF\reportlets\` 后在决策平台目录树中打开。
- 全部 8 个文件已通过：`xml.etree.ElementTree` 解析无异常、首字节非 BOM（`EF BB BF` 不存在）、编码 UTF-8、行尾 LF、含 `<?xml version="1.0" encoding="UTF-8"?>` 声明。
- 数据连接：所有 SQL 数据集均指向连接名 `FRDemo`；若本机连接名不同，全局替换 `<DatabaseName><![CDATA[FRDemo]]></DatabaseName>` 即可。
